# 無人機操作員疲勞監測系統應用定位報告

更新日期：2026-06-11

本報告整理本專案在「無人機駕駛員疲勞狀態監測」主題下的應用定位調整。原始構想偏向軍用無人機長時間任務，但目前研究與驗證場域主要能接觸民用無人機、一般相機、桌面 GUI 與可回放資料。因此，本報告建議將系統定位從單一軍用場景，調整為「民用專業無人機操作員的非接觸式疲勞與警覺度風險輔助系統」。

## 1. 背景與問題

軍用無人機操作員確實可能面臨長時間監控、高壓任務、輪班值勤與警覺度下降等風險，但目前專案無法直接接觸軍用無人機、軍用操作席、軍事任務資料與長航時值勤流程。如果報告仍以軍用無人機作為唯一應用對象，會出現三個問題：

- 場域不可得：無法取得真實軍用任務、操作流程與長時間監控資料。
- 驗證不足：無法證明系統在軍用任務中有效，也難以取得軍方標準作為比較依據。
- 無人機型態差異過大：軍用無人機包含長航時監控、短程戰術、偵察、訓練與多機協同等多種型態，不能用單一民用短航時飛行測試直接代表。

民用無人機單次飛行時間通常較短，許多常見機型約 20 到 40 分鐘就需要返航或換電池。但這不代表民用無人機操作沒有疲勞風險。實務上的疲勞常來自整個工作流程，而不是單趟飛行本身：

- 一天內反覆飛行、換電池、搬運與重新佈署。
- 長時間盯著遙控器、平板、地面站或監控畫面。
- 在清晨、夜間、高溫、強光、戶外噪音或災害現場作業。
- 重複航線巡檢造成單調監控與注意力下降。
- 任務失誤可能造成墜機、財損、空域風險或人員安全問題。

因此，本專案更適合從「單次飛行時間是否很長」改成「操作員在任務前、中、後的狀態是否可被低成本紀錄與提醒」來定義價值。

## 2. 建議系統定位

建議將本系統定位為：

**面向民用專業無人機操作員的非接觸式疲勞與警覺度風險輔助系統，用於飛前狀態檢查、任務中風險提醒、多架次累積疲勞紀錄與訓練評估。**

這個定位有三個好處：

- 可驗證：可在學校、訓練場、民用空拍、巡檢模擬或 UTA-RLDD replay 中建立展示與測試流程。
- 可落地：使用一般攝影機、MediaPipe、rPPG、桌面 GUI、SQLite 與 Web dashboard，不必依賴軍規硬體。
- 可誠實說明限制：系統是風險輔助與趨勢紀錄工具，不是醫療診斷，也不是自動判定操作員可否執行任務的唯一依據。

## 3. 可幫助的無人機操作員

### 3.1 產業巡檢操作員

適用場景包含電力線路、太陽能板、橋梁、港區、工地、建築外牆與大型設備巡檢。這類任務常需要操作員長時間觀看畫面、辨識異常點、維持穩定航線與注意周邊環境。

本系統可提供：

- 飛前操作員狀態檢查。
- 多架次巡檢期間的疲勞趨勢紀錄。
- 長時間盯螢幕造成警覺度下降時的提醒。
- 任務後安全回顧資料。

### 3.2 農業無人機操作員

適用場景包含農地巡查、植保噴灑、作物監測與災損盤點。農業無人機作業常發生在清晨、戶外高溫、強光與長時間移動環境中。雖然單次飛行時間不長，但一天內可能需要多次起降與換電池。

本系統可提供：

- 作業前精神狀態與臉部可偵測品質確認。
- 連續作業後的疲勞累積紀錄。
- 高溫或長時間戶外作業下的狀態趨勢提示。
- 作業排班與休息安排的輔助依據。

### 3.3 公共安全、消防與搜救操作員

適用場景包含火災監控、災害勘查、失蹤者搜尋、交通事故支援與夜間緊急任務。這類任務壓力高、時間不固定，操作員可能需要在待命後快速執行任務。

本系統可提供：

- 高壓任務前的狀態基線紀錄。
- 任務中注意力下降、長閉眼或頭部姿態異常的輔助提醒。
- 任務後回顧操作員是否在高壓或疲勞狀態下執行任務。
- 訓練演練時的壓力與疲勞趨勢觀察。

### 3.4 測繪、工地、礦區與地形調查操作員

測繪與工地任務常包含重複航線、固定高度、固定速度與長時間監控。這類任務的風險不一定來自劇烈操作，而是來自單調任務中的注意力下降。

本系統可提供：

- 重複航線任務中的警覺度輔助監測。
- 長時間坐在地面站或車內監控時的疲勞紀錄。
- 與任務時間、飛行架次、環境條件做事後交叉分析。

### 3.5 商業空拍、影視、活動與新聞操作員

商業空拍常在人群、建築物、活動現場或複雜空域周邊執行。操作員需要同時注意構圖、安全距離、飛行高度、訊號品質與現場干擾。

本系統可提供：

- 高壓拍攝前的狀態提醒。
- 長時間等待拍攝空檔後的注意力狀態檢查。
- 操作失誤風險較高時提供非接觸式輔助警示。

### 3.6 無人機訓練機構與考照單位

訓練場域是本專案最容易落地的應用之一。學員可在模擬任務、長時間練習、考照準備與錯誤修正過程中，被記錄疲勞與警覺度趨勢。

本系統可提供：

- 學員訓練期間的疲勞趨勢紀錄。
- 教官回顧學員在壓力與疲勞狀態下的操作表現。
- 建立「人因安全」訓練教材，而不只訓練操控技巧。
- 在無法取得軍用資料的情況下，建立可重複驗證的民用測試場域。

### 3.7 未來 BVLOS 與多機監控中心操作員

BVLOS（Beyond Visual Line of Sight，超視距操作）與多機監控會讓操作員從「單架無人機操控者」逐漸變成「地面站監控者」。未來若遠距巡檢、物流、公共安全或機隊管理增加，操作員可能需要長時間監看螢幕、處理警示與介入異常狀況。

本系統可提供：

- 遠距監控席的操作員狀態紀錄。
- 多機監控時的疲勞風險趨勢。
- 作為未來人因安全管理與值勤排班的輔助工具。

## 4. 本系統可以解決的問題

### 4.1 補足傳統無人機安全檢查缺口

目前無人機飛前檢查多半重視機體、電池、槳葉、GPS、通訊、天氣、空域與任務設定，但較少量化操作員本身狀態。本系統可以把安全檢查從「只檢查機體」擴展到「同時檢查操作員狀態」。

### 4.2 處理多架次累積疲勞，而不是只看單趟飛行

民用無人機單次飛行較短，但產業任務可能需要一整天多次起降。本系統可記錄任務前、中、後的疲勞分數、品質分數與生理趨勢，協助觀察操作員是否隨著架次增加而狀態下降。

### 4.3 降低穿戴式設備的使用負擔

無人機操作員已經需要攜帶遙控器、平板、電池、對講機、反光背心與其他任務設備。若再要求穿戴胸帶、手環或指夾，可能影響接受度。本系統採用一般攝影機進行非接觸式監測，較適合地面站、教室、筆電與監控中心環境。

### 4.4 建立可稽核的操作員狀態紀錄

系統可透過 SQLite、CSV、Web dashboard 與錄影回放，保存任務中的疲勞分數、行為特徵、rPPG 趨勢與品質診斷。這些資料可作為訓練回顧、演算法調校、工作排班與安全管理參考。

### 4.5 提供非醫療、非強制決策的風險提示

本系統不應宣稱能診斷疾病，也不應單獨決定操作員是否可以飛行。較合理的定位是「輔助提示」：當系統偵測到長閉眼、PERCLOS 上升、頭部姿態異常、rPPG 品質可用且生理趨勢變化時，提醒操作員或教官進行休息、換手或重新檢查。

## 5. 與市面技術相比的差異化

市面上已有許多疲勞偵測、駕駛監控、rPPG 心率估測與臉部狀態分析技術。本專案不應主張「全球首創疲勞偵測」，而應主張「針對無人機操作流程整合與驗證」。

### 5.1 針對無人機操作流程，而不是一般汽車駕駛

汽車駕駛疲勞偵測多半假設使用者坐在駕駛座、面向道路、操作方向盤。無人機操作員則常面向遙控器、平板或地面站螢幕，注意力在飛行畫面、地圖、空域、電量、通訊與現場環境之間切換。

本系統的差異化在於可設計成：

- 飛前狀態檢查。
- 任務中操作員狀態監測。
- 飛後報表與回放。
- 多架次與長時間任務的趨勢紀錄。

### 5.2 低成本、可部署、容易展示

系統使用一般攝影機、OpenCV、MediaPipe、rPPG 訊號處理、PySide6 GUI 與 Web dashboard。相較於醫療級感測器或昂貴專用硬體，較容易部署於訓練教室、地面站筆電與研究展示場域。

### 5.3 非接觸式，不干擾操作

操作員不需要配戴額外感測器。攝影機可以固定在筆電、螢幕或地面站前方，只要臉部可見且光線穩定，即可進行臉部特徵、疲勞行為與 rPPG 趨勢分析。

### 5.4 整合行為疲勞與 rPPG 生理趨勢

本系統不是只做單一指標。它同時包含：

- MediaPipe 臉部特徵點。
- 眼睛開合與 PERCLOS。
- 眨眼時序。
- 頭部姿態。
- 嘴部開合與哈欠輔助判斷。
- rPPG 心率、HRV 趨勢與訊號品質。
- 融合分數與品質 gate。

這種整合能提供比單一閉眼偵測更完整的狀態觀察。但也必須保守說明：rPPG 對光線、頭部動作與相機品質敏感，因此目前最適合作為趨勢輔助，不應作為唯一判斷依據。

### 5.5 重視資料紀錄與可重現驗證

本專案已有桌面 GUI、Web dashboard、SQLite 紀錄、錄影、UTA-RLDD replay 與批次輸出。差異化可以放在「可回放、可稽核、可調校」：

- 能保存每次任務資料。
- 能用固定影片重跑演算法。
- 能比較不同門檻與不同設定。
- 能誠實揭露目前分類能力與限制。

這比只展示一個即時分數更適合作為畢業專題與工程原型。

## 6. 建議主打場景

### 6.1 第一優先：無人機訓練與考照輔助

理由：

- 最容易取得場域與受測者。
- 可用模擬任務或民用無人機練習驗證。
- 可把系統價值放在教學、回顧與安全意識，而不是直接宣稱高準確率。
- 能自然解釋為何系統不是軍規產品，而是人因安全輔助原型。

建議說法：

**本系統可作為無人機訓練場域中的操作員狀態紀錄工具，協助教官觀察學員在長時間練習、重複起降與壓力任務下的警覺度變化。**

### 6.2 第二優先：產業巡檢操作安全輔助

理由：

- 巡檢任務重複、單調、架次多，符合疲勞累積邏輯。
- 可與任務時間、飛行架次、巡檢路線和異常事件做事後比對。
- 商業價值清楚，較接近實際應用。

建議說法：

**本系統可補足產業巡檢無人機作業中操作員狀態難以量化的問題，將疲勞風險從主觀感覺轉為可紀錄、可回放的趨勢資料。**

### 6.3 第三優先：公共安全與救災操作員狀態監測

理由：

- 任務壓力高，疲勞與注意力下降的後果較嚴重。
- 適合用於訓練演練，而不必一開始就進入正式救災場域。
- 能呈現系統在人因安全上的社會價值。

建議說法：

**在消防、搜救與災害應變訓練中，本系統可輔助記錄操作員於高壓、夜間或長時間待命後的狀態變化，作為任務安全管理與訓練回顧依據。**

## 7. 建議畢業專題或簡報敘事

建議不要說：

- 本系統是軍用無人機疲勞偵測系統。
- 本系統可以準確判定所有無人機駕駛是否疲勞。
- 本系統可以取代教官、主管或醫療判斷。
- 本系統已在真實軍用長航時任務中驗證。

建議改說：

- 本系統源自軍用與長時間遠端操作的人因安全需求，但目前以民用專業無人機操作員作為可驗證場域。
- 系統補足傳統無人機安全檢查中較少被量化的「操作員狀態」。
- 系統使用非接觸式攝影機，整合臉部行為疲勞與 rPPG 生理趨勢，提供疲勞風險提示與任務紀錄。
- 系統目前是工程原型與驗證平台，適合訓練、巡檢、演練與研究場域。
- 系統價值不在於宣稱比所有商用品更準，而在於針對無人機作業流程建立可紀錄、可回放、可調校的人因安全工具。

## 8. 可放入論文或企劃書的核心論述

本專案以無人機操作員的人因安全為核心，針對民用專業無人機作業中常被忽略的操作員狀態問題，建置一套非接觸式疲勞與警覺度監測原型。傳統無人機飛行安全檢查多集中於機體、電池、通訊與空域條件，但在連續巡檢、農業作業、公共安全、測繪與訓練場域中，操作員的疲勞、注意力下降與長時間螢幕監控同樣可能影響任務安全。本系統使用一般攝影機結合 MediaPipe 臉部特徵、眼部閉合、頭部姿態、嘴部行為與 rPPG 生理趨勢，提供飛前檢查、任務中提醒與飛後紀錄。系統不作為醫療診斷或單一安全決策依據，而是作為低成本、可部署、可回放的人因風險輔助工具。

## 9. 技術優點與限制

### 9.1 技術優點

- 使用一般攝影機，不需要穿戴設備。
- 可同時輸出行為疲勞、rPPG 生理趨勢與品質診斷。
- 已具備 GUI、Web dashboard、SQLite 紀錄與離線 replay。
- 適合用於訓練、展示、研究與民用專業場域。
- 可用固定影片與任務紀錄反覆驗證與調整門檻。

### 9.2 必須誠實揭露的限制

- rPPG 受光線、頭部動作、相機 FPS、自動曝光與遮擋影響。
- 疲勞判讀受眼鏡、眼型、鏡頭角度、反光與個人差異影響。
- 民用短航時飛行不一定能自然誘發明顯疲勞，需要多架次、長時間模擬或訓練場域驗證。
- 目前可用 UTA-RLDD 作為可重現回放資料，但它不是無人機操作資料集，也不是逐幀疲勞 ground truth。
- 系統目前適合作為輔助提示與趨勢紀錄，不應宣稱為醫療診斷或強制安全判定工具。

## 10. 結論

本系統最適合從「軍用無人機長航時疲勞偵測」調整為「民用專業無人機操作員疲勞與警覺度風險輔助」。這個定位能保留原本關注的人因安全價值，同時避開軍用場域不可得與長航時資料不足的問題。

在應用上，最具可行性的方向是無人機訓練與考照輔助、產業巡檢操作安全、公共安全與救災演練。系統可以解決的核心問題不是「發明全新的疲勞偵測技術」，而是把既有臉部疲勞與 rPPG 技術整合到無人機作業流程中，補足操作員狀態不可見、不可紀錄、不可回放的缺口。

因此，報告與簡報應強調：

- 本系統是非接觸式、低成本、可部署的人因安全輔助系統。
- 本系統針對飛前、任務中、飛後三階段建立操作員狀態紀錄。
- 本系統適合民用專業無人機訓練、巡檢與演練場域。
- 本系統的工程價值在於整合、紀錄、回放與可調校，而不是誇大單次疲勞分類準確率。
