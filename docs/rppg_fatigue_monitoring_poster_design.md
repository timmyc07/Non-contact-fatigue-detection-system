## 5. 摘要

本研究建置一套以一般 RGB 攝影機為核心的無人機操作員疲勞監測系統，結合 MediaPipe Face Landmarker 臉部特徵、rPPG 非接觸式心率估測、眼部閉合與頭部姿態分析，提供即時疲勞狀態、心率趨勢、品質診斷與 Web 儀表板顯示。系統不依賴穿戴式裝置即可進行日常監測；手錶心率僅用於校準 session，透過 BPM offset 修正不同相機、光源與使用者造成的系統性偏差。專案同時支援 SQLite 紀錄、影片回放、UTA-RLDD 資料集批次驗證與 HTML 報表輸出，讓疲勞偵測結果可以被追蹤、比較與回顧。

海報摘要字數建議約 120 到 160 字。若版面有限，可刪除最後一句。

## 6. 研究動機與目標

### 研究動機

本研究最初希望解決軍用無人機駕駛員在長時間遠端操控任務中，可能因疲勞、注意力下降或生理負荷累積而影響工作安全與身體健康的問題。然而軍用場域、資料與任務流程不易取得，也不適合作為學生專題的實際驗證環境。因此，本研究將應用範圍轉向更可落地的固定座位或低移動工作情境，例如監控中心、遠端設備操作、長時間電腦作業、客服值勤、工控室與其他不需頻繁移動位置的工作者，建立一套可用一般攝影機進行長時間狀態觀察的健康與疲勞監測系統。

### 研究目標

1. 建立一套不限於軍用情境、可轉用於多種固定工作場域的非接觸式健康與疲勞監測系統。
2. 使用 MediaPipe 臉部特徵分析眼部閉合、眨眼時序、頭部姿態與嘴部狀態，判斷疲勞與警覺度變化。
3. 整合 rPPG 心率、HRV 趨勢與 SQI 品質指標，作為長時間工作下生理負荷與壓力變化的輔助觀察。
4. 建立個人化 baseline 與 rPPG BPM 校準機制，降低不同使用者、相機、光源與環境造成的偏差。
5. 提供桌面 GUI、Web dashboard、SQLite 紀錄與資料集回放流程，讓系統可即時顯示、長時間記錄並回顧分析。

## 7. 研究方法

建議此區使用「流程圖 + 條列說明」呈現。

### 方法流程

```text
RGB 攝影機影像
  -> MediaPipe Face Landmarker
  -> 臉部 landmark / blendshape / pose matrix
  -> 分流一：行為疲勞特徵
       EAR / PERCLOS / blink / gaze / head pose / yawn
  -> 分流二：rPPG 生理訊號
       ROI 取樣 -> POS -> Butterworth band-pass -> Welch BPM -> HRV/SQI
  -> 品質 gate 與個人化校準
  -> 疲勞融合分數與狀態分級
  -> GUI Overlay / Web dashboard / SQLite / 回放報表
```

### 核心技術

- Face Landmarker：用於臉部 landmark、表情係數與姿態矩陣。
- EAR / PERCLOS：判斷閉眼、眨眼與長時間眼部閉合。
- POS rPPG：從額頭、雙頰與眉間 ROI 的 RGB 微小變化萃取脈波。
- Butterworth band-pass：保留合理心跳頻帶並抑制低頻漂移與高頻雜訊。
- Welch PSD：從頻譜主峰估計 BPM。
- BPM guard：抑制短暫跳值與不合理生理範圍。
- 手錶參考校準：以固定時間窗中位數估計 `watch BPM - rPPG BPM` 的 offset。
- 資料回放驗證：以 UTA-RLDD 影片產生可重現的批次分析結果。

## 10. 研究成果

## 11. 研究結果與未來方向

本研究已建立可即時執行、可視覺化、可記錄並可回放驗證的疲勞監測原型。系統目前以行為疲勞特徵為主要判定依據，rPPG 心率與 HRV 作為輔助趨勢，避免單一生理訊號受光線或動作干擾時造成誤判。未來將持續擴充真人場域資料、提高有效 frame 統計、加入 Bland-Altman 與 MAE 等心率校準評估，並改善不同光源、相機與操作姿態下的穩定性。

未來方向建議條列：

1. 蒐集無人機操作場域真人標註資料，校正疲勞門檻與誤報率。
2. 增加校準報告，包含 MAE、95th percentile error 與 Bland-Altman LoA。
3. 將 Web dashboard 報表整理成任務後疲勞風險摘要。
4. 強化低光源、頭部晃動與遮擋情境下的 ROI 品質 gate。
5. 評估是否加入更完整的 Lab 色彩空間、雙頰 ROI 或深度模型 A/B replay。
